## 📱 Operating systems & robotics

- **Android OS** — set up an environment and explore the operating system.
- **iOS development** — explore the development ecosystem and build a starter project.
- **HarmonyOS, ROS & humanoids** — explore how a humanoid robot can use computer vision to detect objects from a live camera feed.

## 🤖 AI-assisted learning & media

- **Linux networking** — turn a networking book into an AI-assisted tutorial.
- **YouTube + CXL** — create a presentation using Gemini.
- **SystemC** — build an AI-assisted, hands-on tutorial.

## 🖥️ Computer architecture & simulation

- **gem5, cache coherence & hardware ML** — explore cache-coherence behavior, simulate YOLO hardware, and try high-level synthesis (HLS) with testing on Vivado.
- **Dino game + Renode/QEMU** — use the game as a platform for computer-vision-based video anomaly detection, with Renode and QEMU as simulation environments.
- **RISC-V SoC simulator GUI** — investigate whether a Python-based graphical simulator for RISC-V SoCs already exists; if not, prototype one.
- **Software-defined radio** — explore LLM-assisted bit-error-rate reduction with a hardware-in-the-loop simulator. Any jammer-related investigation must remain within a shielded, authorized lab setup.
